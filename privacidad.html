Política de privacidad

Última actualización: 9 de noviembre de 2026

Torre de Control es una aplicación de uso personal que se ejecuta localmente en el ordenador de su propietario. Solo accede a las cuentas que el propio propietario conecta mediante el inicio de sesión oficial de cada plataforma (Google/YouTube, Meta y TikTok).

Qué datos usa

  • Tokens de acceso de las cuentas conectadas, para publicar contenido y leer estadísticas.
  • Los archivos de vídeo e imagen que el propietario elige publicar, incluidos los de su propia carpeta de Google Drive (acceso de solo lectura).
  • Estadísticas públicas y privadas de las propias cuentas (seguidores, vistas, interacciones).

Dónde se guardan

Todo se guarda únicamente en el ordenador del propietario. No se envía a servidores propios ni a terceros, salvo a las API oficiales de cada plataforma para realizar las acciones solicitadas.

Uso de los datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Los datos de YouTube y Drive solo se usan para publicar vídeos en el canal del propietario y mostrarle sus estadísticas.

Revocar el acceso

El acceso puede retirarse en cualquier momento desde el propio panel de la aplicación o desde la configuración de seguridad de cada plataforma (por ejemplo, myaccount.google.com/permissions).
